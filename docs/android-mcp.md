# Android 原生 MCP 诊断

入口：软件设置 → 诊断日志 → MCP 诊断连接。

开启一次临时会话后，可以通过 MCP 读取 Android 宿主的状态、权限、日志和已保存的游戏截图。接口在 APK 内，不修改 Mower 本体，不依赖 Python、WebUI、Shizuku 或游戏服务启动；服务启动失败时也可使用。

## 连接

1. 在手机开启诊断会话，点击「查看连接信息」→「复制连接信息」。
2. 电脑通过已授权的 USB 或无线 ADB 连接手机，将复制内容中的 `<手机设备序列号>` 替换为 `adb devices` 中的设备序列号，执行转发命令。手机端口每次会话变化；电脑端口示例为 18765，可以自行更改。
3. 将复制的 `mcpServers` 配置加入支持 Streamable HTTP 的 MCP 客户端。不同客户端的配置语法可能不同；必要字段是 URL 和 Authorization 请求头。

```sh
adb -s <手机设备序列号> forward tcp:18765 tcp:<本次手机端口>
```

```json
{
  "mcpServers": {
    "mower-android": {
      "url": "http://127.0.0.1:18765/mcp",
      "headers": { "Authorization": "Bearer <本次临时密钥>" }
    }
  }
}
```

会话 30 分钟后结束，可在手机诊断页或通知中提前关闭。关闭后已有连接断开、端口关闭、临时密钥失效。进程退出或覆盖安装也会关闭会话，不会在重启后自动开启。结束后可以删除电脑转发：

```sh
adb -s <手机设备序列号> forward --remove tcp:18765
```

默认关闭，只监听手机 127.0.0.1；不绑定局域网地址、不复用 WebUI Token。临时密钥不落盘、不写日志，仅在手机连接信息弹窗中显示，用户复制时进入剪贴板。请勿将包含密钥的完整连接信息发布到公开页面。

## 工具

| 工具 | 内容 |
| --- | --- |
| `android_status` | APK 版本/安装时间、Android 版本、服务状态、亮屏/锁屏、电池休眠、授权状态、可用空间、网络历史和系统记录的最近进程退出原因 |
| `read_logs` | `source` 选择 `mower`、`console`、`network` 或 `startup`；可传 `since` / `until`（Unix 毫秒）；默认最近两小时 |
| `list_screenshots` | 同一时间范围内的截图 ID、时间、大小、总占用；100 张一页，通过 `offset` 翻页；响应返回固定的 `since` / `until`，后续分页应复用它们 |
| `read_screenshot` | 传列表返回的 `id`，返回一张原图的 MCP image 内容；单张最多 8 MiB |

Mower 日志最多读取最近四个轮转文件，各末尾 128 KiB；控制台和网络日志各末尾 128 KiB，超限有标记。启动检查与系统状态反映最近一次/当前情况，不受时间范围限制。纯文本会沿用诊断导出的 Token 脱敏。截图不做图像脱敏，可能含游戏账号信息。

接口只读，不提供 shell、任意路径读取、修改配置、删除日志、解锁、截图写盘开关或排班操作。截图来自 Mower 已保存的游戏截图目录，不截取手机当前页面，不读取解锁录制。图片被原清理逻辑删除后返回读取失败；接口不改变截图保留设置。

## 协议与开销

- Streamable HTTP，`POST /mcp`，JSON-RPC 2.0，支持 initialize、ping、tools/list、tools/call 和无响应通知。
- 无状态 JSON 响应，不维护 SSE；GET 返回 405，通知返回 202。
- 支持协议版本 2025-11-25、2025-06-18、2025-03-26。
- 要求 Bearer 认证；拒绝浏览器 Origin、非本机 Host、重复请求头、分块请求体及不支持的协议版本。
- 请求体最多 16 KiB，请求头最多 8 KiB，读取超时 5 秒；最多两个执行线程和两个排队连接。
- 无请求时不扫描文件，不维持 CPU 唤醒锁，不轮询游戏。只有开启会话时保留独立前台通知。手机深度休眠可能暂时无法响应。

本接口独立于原生诊断 ZIP 导出与清理功能，不通过 MCP 删除文件。游戏截图按现有规则保存；已清理的历史截图仍无法恢复。
