# 游戏静音恢复

后台静音使用系统的 `PLAY_AUDIO` 权限，不改变手机媒体音量。原实现仅在应用侧保存恢复记录，强退跳过应用清理后可能留下静音；恢复按钮也只处理有记录的包，记录缺失时无法修复。

提权后台进程现在独立保存修改前的包级权限，收到应用死亡通知或停止后台显示时恢复。销毁调用等待清理执行，不先退出进程。应用侧的持久记录继续用于后台进程也异常退出后的重试。自动清理只撤销本应用拥有的修改，保留用户原本或后来设置的权限。

用户主动点击「关闭静音并恢复声音」时，关闭自动静音，检查已安装官服与 B 服的包级和 UID 级 `PLAY_AUDIO`，解除 `ignore` / `deny` 并再次读取确认。该操作不依赖历史记录，也不需要启动 Python 服务、排班或后台游戏；仍需 Shizuku / Root 授权。读取、修改或验证失败会显示错误，不报告恢复成功。只修改声音权限，不重置游戏的其他权限。

本地验证覆盖重复静音、应用退出后的原值恢复、外部设置保留、部分失败重试、UID 与包级权限解析及手动恢复后的实际状态校验。尚需连接手机验证真实强退、重新打开游戏及实际声音播放。
