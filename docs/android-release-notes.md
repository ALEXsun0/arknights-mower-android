## 宿主更新

- 修正游戏声音恢复：区分系统默认允许与显式 default，清理旧版残留记录，避免强退时再次写回 default 静音；独立后台进程在收到主进程死亡通知后执行恢复，恢复失败显示错误。真实强退后的声音效果仍需实机确认。
- 诊断日志支持按时间段导出、选择附带截图、预览大小与清理；原生 MCP 诊断入口需用户手动启用。
- 原生主页与设置支持竖屏，旋转时保留 WebUI 与表单；记录网络状态变化以便排查更新连接。
- 覆盖安装后首次启动服务应用 APK 内置的 Mower 与 MAA，保留排班、配置及局域网设置；普通重启保留后续热更新。
- 自动发行使用 main 上的宿主修复。Mower 有官方 Android 更新 ZIP 时优先使用官方归档；实际组件版本与构建来源见本页上方及 distribution.json。
- APK 沿用原签名。需要 Android 8.1+、ARM64，以及可用的 Shizuku / Root 授权；首次启动需解压运行资源。

历史版本说明保留在仓库 docs/android-release-history.md。版本、组件及 Python 接口适用范围由本次构建元数据生成，不沿用旧版固定版本文字。
