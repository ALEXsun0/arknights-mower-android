- 地图拖动后重新定位房间，减少重复识别；保留宿舍单回两轮流程。排班修改后重新生成宿舍优先级，避免旧排序残留；纳入 #1038 最新的保存失败状态恢复，保证重试仍能正确刷新优先级。

- MAA Python 接口内容未变，保持原版本和兼容范围。长期排班效果仍需后续运行日志确认，不宣称已解决所有低帧率问题。

### 相较上一公开版本累计包含

- 同时包含此前的 Android 兼容合并、专精技能等级校验、宿舍职业筛选/失败重选及日志版本显示修复。
- 局域网自定义 Token 取消长度上下限，留空仍自动生成；修复短 Token 导致端口与令牌均未保存。
- 手机数字框支持数字键盘提示，触摸加减按钮不再聚焦输入框；Android 禁用横屏输入法全屏编辑。
- 修复倒计时数字识别器漏传截图宽高导致连续读取失败；新增关于软件，集中显示版本、GitHub 项目与 APK 更新入口。
- 修复锁屏/后台后首页仍持续刷新窗口的问题；亮屏标志仅在值变化时提交，首页与游戏预览的刷新按可见状态启停，权限检查移到后台并去重。
- 修复选干员长滑动被边界校验拒绝导致的卡死，以及跑单倒计时未调用专用数字识别器的问题；首页与 WebUI 跑单设置提示统一为：Android 推荐保持「跑单前置延时」5 分钟、「葛朗台缓冲时间」15 秒；前者为导航选人留余量，后者为确认入驻留余量。两项均可自行修改；设备较慢时可适当增加。
- 权限与后台运行集中到独立原生板块并自动检测；自动生成的局域网端口和 Token 保存后重启复用，自定义保存失败会明确提示。
- 通过实际运行验证后在后台清理旧程序、环境和 MAA/Python 接口备份；桌面清理失败跨重启重试，Android 新环境启动失败保留回退。
- 修复解锁录制的横竖屏采样时机：按实际触摸记录锁屏方向，回放前等待布局稳定。三星 SM-G9880 已完成重新录制和解锁测试。
- Python 兼容接口支持WebUI 中检查、热更新、拖拽导入和自动检查，按内容判断更新，运行中任务保持原接口。
- 截图保存由原生设置接管，默认 0 小时；局域网支持固定端口和自定义 Token。
- 后台游戏、解锁录制、声音、锁屏、画中画、日志和任务收尾均在原生设置中管理。
- MAA 使用官方 Android ARM64 核心与资源，暂不使用 Mirror酱；Mower 使用主仓库 Android 更新包。

APK 保留原签名，可覆盖安装。需要 Android 8.1+、ARM64；未 Root 手机需要启动并授权 Shizuku，也支持已配置的 Sui / Root 后端。首次安装需解压运行资源。构建兼容检查不等于全部设备、所有 MAA 任务或长期排班均已实测。
